# Kechap 사용자 과제 파일럿 참가 안내·동의

문구 version: **kechap-study-consent-v1** / 프로토콜: kechap-human-pilot-v1

**현재는 연구 준비 문서입니다. 참가자를 모집했거나 동의를 받았다는 기록이 아닙니다.** 실제 모집 전 운영자는 다음 정보를 채워 보여 주어야 합니다. 비어 있으면 참가를 시작하지 않습니다.

- 연구 운영자·책임자: **미설정 — 모집 전 입력 필요**
- 문의·철회 접수 경로: **미설정 — 모집 전 입력 필요**
- 참가 기간과 비공개 데이터 삭제일: **미설정 — 모집 전 입력 필요, 최대30일**
- 참가 보상·중단 시 지급 조건: **미설정 — 모집 전 입력 필요, 중단 불이익 금지**
- 예상 소요: 안내·연습 포함 약5~10분. 실제 과제 시간과 별개이며 언제든 중단할 수 있습니다.

## 무엇을 하나요

사람 검증을 도입할 때 과제가 얼마나 빠르고 불편한지 알아보는 소규모 연구입니다. 화면 선택, 물체 이동·회전, 순서에 맞춘 반응의 세 가지 자체 실험 과제를 합니다. 각 과제에서 최대 두 번 시도할 수 있습니다. 게임 실력·지능·장애 정도를 평가하는 목적이 아닙니다. 성공해도 실제 사람·본인 신원·유일한 사람임이 증명되는 것은 아닙니다.

다른 사이트의 CAPTCHA를 대신 해결하지 않습니다. 제품 계정을 생성하지 않으며 결제·리워드 지급을 요구하지 않습니다. 카메라·마이크·얼굴·목소리·정부 신분증을 제공하지 않습니다.

## 불편하거나 어려우면

언제든 멈추거나 건너뛸 수 있습니다. 실패·중단·보조공학 사용 때문에 계정이나 서비스 이용에 불이익을 받지 않습니다. 과제의 시간 제한이나 움직임이 불편하면 즉시 중단할 수 있습니다. 지원되는 실제 대체 경로와 그것이 무엇을 확인하는지 운영자가 먼저 설명해야 합니다. 지원 메일이 있다는 이유만으로 즉시 같은 보장을 제공한다고 표시하지 않습니다.

## 어떤 정보를 기록하나요

연구용 무작위 ID, 동의 문구 version, coarse 기기 종류(desktop/mobile/tablet/미기재), 선택적으로 알려 준 접근성 이용 형태, 순서·시도 수·성공/거절/오류/중단, 실제 소요 시간, 서버 검증 CPU와 관찰된 비용만 기록합니다. 장애 진단이나 의료기록은 요구하지 않습니다. 접근성 태그와 기기 정보는 미기재를 선택할 수 있습니다.

이름·연락처·IP·정확한 브라우저 fingerprint·영상·음성은 연구 JSONL에 저장하지 않습니다. 입력 이벤트는 서버가 과제의 규칙을 검증할 때만 처리하고 기본적으로 즉시 폐기합니다. 디버깅이나 독립 판정을 위해 별도 자료가 필요하면 무엇을 얼마나 보관할지 별도로 설명하고 동의를 받아야 합니다. 원치 않으면 제공하지 않아도 됩니다.

과제 요청을 처리하는 네트워크 서버는 연결 정보를 일시적으로 처리할 수 있습니다. 운영자는 reverse proxy·호스팅 로그에서도 IP·토큰의 장기 기록을 막고 연구 데이터 보존 정책과 별도로 실제 처리 위치·제3자 서비스가 있으면 알려야 합니다. 현재 프로토콜은 자체 실험 과제만 사용합니다.

## 보관·철회·공개

참가 시 별도의 **철회 코드**를 받습니다. 코드 원문은 본인이 보관하고 서버에는 hash만 둡니다. 이름을 저장하지 않으므로 코드를 잃으면 자신의 기록을 찾기 어려울 수 있습니다. 문의 경로로 철회 코드를 제시하면 해당 연구 ID의 과거 기록을 삭제하고 공개 집계를 다시 계산합니다. 운영자는 이 코드를 GitHub 이슈나 공개 채팅에 올리도록 요구하지 않습니다.

비공개 기록은 안내한 삭제일까지 최대30일 보관하고 그 이후 삭제합니다. 참가자 ID가 없는 집계 결과·실험 코드·표본 수·한계는 공개할 수 있습니다. 작은 기기·접근성 그룹은 5명 미만이면 수치를 숨깁니다. 공개된 집계만으로 개인을 확인할 수 없도록 최소화하지만, 이미 다른 사람이 내려받은 집계를 완전히 회수할 수는 없습니다.

## 선택 확인

운영자와 문의·철회·보상·삭제일을 확인한 뒤 **기본 선택되지 않은** 동의 버튼을 사용합니다.

- [ ] 설명을 읽었고 자발적으로 참가합니다. 언제든 중단·철회할 수 있음을 이해했습니다.
- [ ] 위에 설명된 최소 연구 데이터를 안내한 기간 동안 처리하고 비개인 집계를 공개하는 데 동의합니다.

동의하지 않으면 연구는 시작하지 않으며 불이익이 없습니다. 이 문서는 동의의 실제 수집·기관 승인·개인정보 적합성 판정을 대신하지 않습니다.
