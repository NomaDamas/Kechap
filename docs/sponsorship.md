# Kechap 후원

저장소의 `.github/FUNDING.yml`은 GitHub Sponsors 대상 계정을 `NomaDamas`로 설정한다. 후원금은 공급자 조사, 버전별 통합 유지보수, 접근성 검증과 공개 벤치마크 운영에 사용하는 방향이다. 후원 여부는 공급자의 보안 승인·추천 순위를 결정하지 않는다.

2026-11-12 GitHub GraphQL 조회에서 `NomaDamas` 조직과 현재 로그인 개인 계정 모두 `hasSponsorsListing=false`였다. 따라서 저장소 설정을 게시하는 것만으로 결제 수령이 활성화되지는 않는다. 조직 소유자는 https://github.com/sponsors/accounts 에서 조직의 Sponsors 가입 가능 여부를 확인하고 지급·세금·계정 심사 등 요구 사항을 완료해야 한다. 활성화 전 실제 후원을 받을 수 있다고 홍보하지 않는다.

후원 수령 주체를 개인이나 다른 조직으로 바꾸려면 해당 계정 소유자의 의도와 활성 listing을 확인한 뒤 FUNDING.yml을 수정한다. 비밀 지급 정보는 저장소나 이슈에 기록하지 않는다.
